# 付録C 表示文言マスタ

結果画面に表示される定型文と、その出し分け条件の一覧です。既存システムの管理画面（admin_page）の要素定義から抽出しました。新システムでは、これらをマスタデータ（DB またはコード内定数）として保持し、同じ条件で出し分けます。

表記: 「R」は閲覧中の回答データ、「U」は比較組織選択時に管理者アカウントに一時保存される計算値を指します。

```

```

```
Analyticalタイプの人は、落ち着いた環境でコツコツと専門性を高めていくのが得意です。物事を深く掘り下げ、知識や技術を磨き続ける姿勢が強みです。研究者や職人のように、一つの分野で信頼できる存在になることができます。
ただし、慎重になりすぎて新しい挑戦に踏み出すのが遅れることもあります。そのため、周囲から背中を押してもらうことでより力を発揮できるタイプです。
```

```
Drivingタイプは、目標を掲げて突き進み、周りを引っ張っていく力があります。新しい取り組みや変化を恐れず、リーダーシップを発揮して成果を出すことに喜びを感じます。
組織にとっては成長を加速させる存在ですが、一方で強引に見られたり、協調性に欠ける印象を与えてしまうこともあります。周囲の意見を取り入れながら進めると、リーダーとしてより信頼されるタイプです。
```

```
Expressiveタイプは、人とのつながりを大切にし、場を明るくする存在です。人と話すことが好きで、感情表現も豊か。チームの雰囲気を盛り上げたり、コミュニケーションの橋渡しをするのが得意です。
その反面、感情に左右されやすかったり、計画を継続するのが苦手なこともあります。周囲のサポートを受けながら、持ち前の明るさを活かすと、組織に欠かせないムードメーカーになります。
```
