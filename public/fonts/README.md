# public/fonts

PDF の印刷用ページだけが `@font-face` で読み込む日本語フォントです（07 §9.7、D07-20）。画面はシステムフォントのままです。

| ファイル                   | 内容                                                                       |
| -------------------------- | -------------------------------------------------------------------------- |
| `NotoSansJP-Regular.woff2` | Noto Sans JP Regular（ウェイト 400、Version 2.004）を woff2 に変換したもの |
| `NotoSansJP-Bold.woff2`    | Noto Sans JP Bold（ウェイト 700、Version 2.004）を woff2 に変換したもの    |
| `OFL.txt`                  | SIL Open Font License 1.1（google/fonts の `ofl/notosansjp/OFL.txt`）      |

- 入手元: Google Fonts（`fonts.gstatic.com` の TrueType）。fontTools で woff2 に変換しただけで、サブセット化はしていません（07 §9.7）。
- ライセンス: SIL Open Font License 1.1。フォントを再配布する場合は `OFL.txt` を同梱してください。
